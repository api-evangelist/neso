# National Energy System Operator (NESO)

> NESO is Great Britain's publicly owned, operationally independent electricity system operator and whole-energy system planner. It runs two live, fully anonymous public APIs: the NESO Data Portal API (CKAN 2.8.7, 128 open datasets on GB electricity demand, generation, balancing, constraints, interconnectors, connection registers, network charges and Future Energy Scenarios) and the Carbon Intensity API for Great Britain (national and regional carbon intensity, forecast up to 48 hours ahead, half-hourly generation mix and per-fuel emission factors). No API key, no registration, no application. Generated by API Evangelist from the NESO catalog entry; NESO does not publish an llms.txt.

## APIs

- [NESO Data Portal API](https://www.neso.energy/data-portal/api-guidance): CKAN Action API 3 at https://api.neso.energy/api/3/action - package_list, package_search, package_show, organization_list, tag_list, resource_search, resource_show, datastore_search, datastore_search_sql (read-only PostgreSQL). Anonymous.
- [Carbon Intensity API](https://carbon-intensity.github.io/api-definitions/): REST/JSON at https://api.carbonintensity.org.uk - 33 documented GET paths across national intensity, statistics, generation mix and regional breakdowns by DNO region, region id or postcode. Anonymous.

## Rules for agents

- Send no credentials. Both APIs are anonymous; an Authorization header is unnecessary and ignored.
- Respect the published rate guidance: at most 1 request per second to the CKAN API and 2 requests per minute to the Datastore API. NESO blocks IP addresses that degrade the service.
- Do not poll data files for change. Call resource_show?id={resource_id} and compare last_modified before fetching.
- Everything is read-only. There is no public write operation on either API, and no idempotency contract exists because none is needed.
- Attribute redistributed Data Portal data as "Supported by National Energy SO Open Data".
- Times are ISO 8601 UTC and the native grain is the GB half-hour settlement period.
- There is no consumer or customer data here. NESO holds no retail relationships; GB smart-meter consumption data moves through the Smart DCC, not the system operator.
